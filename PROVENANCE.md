# Source, dependencies and privacy review

SpeedPeek derives from the earlier MenuMeter v0.2 source. The available source directory had no Git repository/history and no third-party attribution or license file. Files were inspected in full. Earlier authorship cannot be independently established from these files alone. The project owner authorized this source release under MIT. AI-assisted preparation is not evidence of ownership or clearance.

## Inventory

- Swift app, sampler, tests and renderer: inherited local v0.2 sources with rename/build/login changes. No copied third-party headers or package imports were identified. Earlier authorship remains unverified.
- Icon: generated by `IconGenerator.swift` from rounded rectangles and arrow paths using AppKit; no downloaded image, embedded font, asset catalog or external icon library. The source establishes how the current asset is made, not independent proof of earlier design ownership. The icon generator is included in the MIT source release.
- `package-icon.py`: Python standard library (`pathlib`, `struct`), inherited local source; no pip dependencies.
- Runtime dependencies: Apple AppKit, Foundation, SystemConfiguration, ServiceManagement and Darwin APIs, provided by macOS. No SDK/framework binaries are vendored. Apple SDK/toolchain terms apply separately; the project MIT license does not relicense Apple components.
- Build tools: Apple Swift compiler, codesign, plutil, zsh and Python 3; no package manager, external package lockfile or fetched code.
- MIT text: standard [MIT License](https://opensource.org/license/mit). Copyright attribution: SpeedPeek contributors.

## Privacy

Inspection found interface discovery, local counters, menu rendering, login registration and a developer-only resource measurement mode. No URLSession, HTTP client, analytics SDK, credential reading, packet capture or file-based traffic history is present. `--measure-seconds N` prints CPU/RSS/tick counts to stdout and exits. `--render-preview PATH` writes a synthetic display preview, not a desktop screenshot.

This repository contains source files and project documentation only. `.build`, generated apps, logs, previews and `.DS_Store` are ignored. Original archives and local review records are outside the source directory and must not be published with it.

## Coverage limits

No independent trademark or name-availability clearance was performed. No third-party package or downloaded asset was identified during source inspection; this is not independent proof of the earlier authorship of inherited source. macOS 13 and Intel runtime behavior remain untested. This is a source-only release, without a Developer ID signed or notarized binary.
